Concept Map Guide & Shortcuts

Interactive Node Drag-Resizing & Layout

Fit Screen Arranges visible nodes across the screen area in an even grid. Fit Grid in Box Select nodes, click Fit Grid in Box, then drag a rectangle. Nodes are laid out in a grid that fits inside the rectangle (Esc cancels). Fit Sequence in Region Select nodes, click Fit Sequence in Region, then drag a rectangle. Nodes are placed in one diagonal line from the top-left to the bottom-right corner, ordered by arrow direction (otherwise creation order). Highlight Chain Click a single node to recolor its arrow chain: amber lines feed into it (upstream), pink lines lead out of it (downstream), all other lines dim. Colors are temporary and never saved. Scrolling Scrollbars appear when nodes extend past the canvas; use the mouse wheel or drag the bars. Resize Selected Node Click any node to select it, then drag the bottom-right corner handle (◢) to give it a custom fixed dimension. Auto-size Checkbox Select a node and check Auto-size Node in the toolbar to clear custom dimensions and restore standard dynamic fitting.

Menu Docking & Panel Resizing

Dock Selector Switch menu docking between Top, Bottom, Left, Right, or Floating. Resize Side Panel When docked Left or Right, drag the border resizer bar to shrink or widen the control panel.

Node & Text Operations

Double Click Node If Edit Text mode is active: Edit text inline directly in the box.
If Edit Text mode is off: Opens URL in a new tab (if a URL exists). [-]/[+] Toggle Click to collapse or expand subtrees attached to the node. × Button Hover over a node and click the red cross to delete it.

Shortcuts & Selection

Undo / Redo Use Ctrl + Z (Cmd + Z) to Undo, and Ctrl + Y or Ctrl + Shift + Z (Cmd + Shift + Z) to Redo. Create Line Check Create Line, choose a Type (Arrow or Line), then click a source node and a target node. TXT Simple format Nodes: id label x y
Arrow: -1 fromId toId
Line: -2 fromId toId Drag Canvas Click and drag on empty canvas background to box-select multiple nodes. Ctrl / Cmd + Click Toggle selection of multiple individual nodes.
