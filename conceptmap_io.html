Save & Export

Save actions operate on the main concept map, so its active file target and filename stay consistent with Ctrl+S.
Save Options
Save format: TXT Extended Lines (change it in the main menu).
Active filename
No file linked yet. Save will ask where to save.
Bulk Save Options
Copies matching source files byte-for-byte into the first available new, new2, etc. folder. It does not replace those source files with the current canvas.
Mobile tip: Save may open the share sheet; choose Save to Files and pick a folder you recognize.
Export Options
Extended Lines stores node coordinates, connections and metadata. TXT Simple stores node rows and line identifiers. TXT Indent stores a hierarchical outline.

Import

Drop a map file here (.json, .txt, .html), or choose an import format below.
Opening/dropping any map file auto-detects format (JSON, TXT Extended, TXT Simple, TXT Indent, HTML).

History States

Jump to, or delete, recorded history states. History entries show counts and are managed by the main map.
